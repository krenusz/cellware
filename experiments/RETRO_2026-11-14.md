## What went wrong
1. **C9-S2 was declared "ready" on an optimistic power.** On 11-11 the plan-stage power (0.84) used train CV rho 0.30 with no shrink. Spent partitions were available to give an out-of-sample estimate, and they say 0.71. Had we run C9-S2 on 11-11, it would have been an under-powered look at the last partition.
   - **Lesson:** where spent partitions of the same dataset exist, power for a new sealed look comes from the out-of-sample effect on them, not train CV.
2. **The chapter pipeline is limited by data, not ideas.**
   - Chapters 4, 5, 9-S2 and 10 (primary) all ended data-limited; chapter 6 ended exploratory.
   - Every powered result so far (ch7, ch8, C10-S2) used **many clones as the unit with no between-condition contrast**.
   - The pattern is clear: Cellware's tests work when the unit is a clone/lineage and n >= ~100 per sealed partition. They fail when the question needs replicated conditions (libraries, gastruloids, mice).
3. **Data search was reactive.** We kept re-checking a fixed watch list rather than scanning for datasets shaped like our successful designs. Today's scan found one new candidate (LSC LARRY, Zenodo, public since 31 Jan 2026) that the watch list would never have surfaced.
4. **Re-reading the unchanged watch list costs a step each time.**

## Lessons -> landing (H-retro rule: every lesson lands)
1. **Practice line (proposed, pending Bence):** power for a sealed look uses the out-of-sample effect on spent partitions of the same dataset when any exist. Train CV with a guessed shrink is used only when none exist.
2. **Practice line (proposed, pending Bence):** a data search scores candidates by the shape of past successes:
   - clone/lineage unit;
   - >= ~100 units per sealed partition after a 40/20/20/20 split;
   - state measured before the fate readout;
   - public now.
   Replicated-condition contrasts need >= 3 per arm (H22) and are scored second.
