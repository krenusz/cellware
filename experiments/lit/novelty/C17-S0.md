## Planned findings
- Finding: one generative clone model (shared state, memory, instruction, selection, split and sampling rules, with per-system scales) fitted jointly to the train portions of several systems predicts the clone statistics of a system it never saw (leave-one-system-out) better than a per-system baseline.
  - Verdict: not found
  - Papers: LineageFlow 2026 (bioRxiv 10.64898/2026.10.17.759846; growth-corrected fate forecasting, per data set); Deep Lineage (Cell Systems 2026); DestinyNet (Patterns 2025); Clonotrace (PMC12486112). All fit one data set at a time; none shares mechanistic parameters across systems or tests transfer to an unseen system.
- Finding: per-cell-class memory, instruction and selection parameters, compared across systems on one scale, follow a simple law (for example, memory loss per division scales with potency).
  - Verdict: not found
  - Papers: our own C5-S2 (memory differs between blood progenitors and ES clones); no cross-system parameter table found.
- Finding: transcription-factor perturbation effects, projected into the gene-program space of a lineage data set, identify which factors move cells along the inherited (clone-shared, fate-predictive) axis.
  - Verdict: partly published
  - Papers: human cortical Perturb-seq with STICR lineage barcodes (Nature 2025, doi 10.1038/s41586-025-09997-7): perturbation and lineage in the same cells, one system, fate plasticity per factor. Barcoded monoclonal embryoids (bioRxiv 10.1101/2025.05.23.655669): bottlenecks confound mosaic TF screens. Joining separate perturbation and lineage data sets on the inherited axis: not found.
- Finding: a pooled table of clone statistics (sister agreement, memory per division, fate coupling) across many public barcoding studies shows cross-system regularities.
  - Verdict: partly published
  - Papers: "Universality of clone dynamics during tissue development" (arXiv 1909.01439; clone sizes collapse to a log-normal form across tissues); universal clone-size theory (arXiv 1604.04936). Pooled memory or sister-agreement statistics: not found.
