## The chapter in one paragraph
C17 set out to build one generative model of clone behaviour across systems and test whether a shared law holds across classes. It produced a parameter table (blood 3, pluripotent 3, neural 1), now with a `scale` column so that only like-for-like parameters are compared. **No claim:** the cross-class law test is not feasible on any scale (no scale has >= 3 systems in two classes), and the stage-aware memory model was **NOT SUPPORTED** in three powered fits on the dated embryo tree (commitment carries the fit; memory per division edge adds little). The last within-system idea (W5, memory per edge differing early vs late) was dropped at its gate: a same-size commitment step passes its rule 95% of the time, so the data cannot attribute it to memory. The question that remains (does memory decay per division or per unit of time?) needs a system with **counted** divisions; two searches found none public (imaging genealogies are kept on request). **No sealed partition was read in C17; every A/B/C stays intact** (dtt_founder, crest_split_clone, rf2020_clone, cortical_clone).

## Went right
1. **Pretest before proposing held** (practice from RETRO_2026-11-21). W1-W7 were screened on spent numbers; only W5 survived, and a gate against its closest control removed it before any real agreement was read.
2. **The control was chosen by the confound, not by convenience.** Early/late was defined by the same date that drives commitment, so the control (M_cstep) was a commitment step of the same size. This turned a power PASS (P4) into a correct drop (P5).
3. **A crash became an amendment before any result** (P5: the matched-step solver had no root; replaced by the closest-fit control and logged first).
4. **Searches carried recall gates** and the failures were reported as incomplete, not as "nothing exists" (P7: 1 of 2 held-out known studies found).

## Went wrong (each lesson lands)
1. **A same-covariate new term was first powered against the null, not against the control that mimics it** (P4 PASS, then P5 FAIL).
   -> practice already landed (program.md, 2026-11-22): a new term on the same covariate is powered against a same-size curve-bending control.
2. **Literature tools failed silently on this machine** (OpenAlex 503, Semantic Scholar 429, Europe PMC full text 500), costing a pass.
   -> practice: literature maps run on Actions (lit_gap.py); local Europe PMC only for short lookups (memory updated).
3. **The chapter ran on after its feasible tests were spent.** After C17-S1R-P2 (law test infeasible) and the three stage-aware negatives, four more steps went into searches and screens with low prior.
   -> practice (program.md, "Before proposing next steps"): when every pretested option of a chapter is spent, list the owed items from other chapters (e.g. a power redo) among the next steps.
