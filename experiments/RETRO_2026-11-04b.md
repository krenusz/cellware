# Retro, 2026-11-04 (evening)

Covers E41b, B23-B26, the B7 fit-set audit, E42 probes, E43, the S series start (survey, S2).

## What went well

- **Pre-registration paid off three times.** E42 was killed by a direction probe before any fit.
  E43's direction check was run as registered and reported. B26's formal reading was caught as
  resting on one clone.
- **Suspicion turned into an audit.** Bence's "this is suspicious, check it" about B7 G led to
  the fit-set audit. The B7 data value and simulated interval both used held-out shard-1 clones.
  On the fit set, B7 G is marginal (E38 5/9 gated, primary 3/9), not the firm misfit we had
  reported. The record now says so.
- **Data-only diagnostics found the shape of the misfit.** B24 found large M-pure clones with only
  2-3 cells under G-CSF (15% vs 2%) and too many shared clones (57 vs 39). B26 found that E38 has
  too few large M-pure clones (16+ cells: 5 vs 0.8). B25 showed that the low M-CSF replicate
  agreement is sampling, so the planned down-weighting was dropped before it could double-count
  noise.
- **Tooling fixed.** The guard now judges every seed at run end. run_sweep no longer skips results
  silently. e33 computes B7 on the fit set.

## What went badly

- **Design errors got into two pre-registrations.** E43's class was monocyte-only "in every
  condition" without checking the Epo/SCF consequence (all seeds failed the gate on Epo/SCF).
  B26's readings had no minimum count. New rule: **every reading states a minimum sample size**,
  and every model change is checked against every condition's statistics before registration.
- **A smoke test corrupted a run's output.** A stubbed json.dump still opened the output file,
  leaving an empty B23 result that run_sweep then skipped. Smoke tests now write to the scratchpad.
- **S2's E38 estimator needed two amendments.** Both were disclosed before the real run, but the
  first smoke test used real counts, so S2's R2 (m3 vs E38) is spent. Lesson: smoke tests use
  synthetic outcomes, not just synthetic inputs, when a comparison involves real data.
- **Claims outran the evidence once.** B24 said the simulation used the fit set; it did not.
  Corrected in the log the same day.

## Decisions

1. E38 stays the reference, with its protocol verdict: 9/18 gated, primary 3/9, not stable.
2. The B7 G misfit is marginal. The robust misfit is the clone-size structure of monocyte-pure
   clones (B24 D3, B26 size table), which also shows as E38's poor per-clone calibration (S2 side
   observation: confident misses on large pure clones).
3. The next mechanistic candidate is E44: a monocyte-leaning clone class acting only in the
   myeloid wells, judged on the gate and primary plus B24 D3 and B26's size table, with minimum
   counts. Pre-register next session.
4. The held-out test stays unspent.
5. S series: S1 (images) is blocked. The public Buggenthin data is a 2-cell demo, and no
   multi-cytokine time-lapse set is public. S2 runs now.
