# Retro 2026-11-19: C17-S1 amendments 1-4 (H18, before a 5th amendment)

Scope: C17 from the S1-S3 pre-registration (2026-11-18) through amendments 1-4 and S1 runs 1-2 (synthetic smoke + train counts). Bence: "1" (retro, then re-scope the cortical rule). Analysis: Opus 5.5. No sealed partition read; no test statistic on real data yet.

## In one line
Four amendments in one step, each for a real reason: novelty (1-3: the split test re-aimed at the unpublished part, with the published part as control) and method (4: detection floor). But the pass rule written in amendment 4 tested a regime (floor 5) the data never occupy, so a usable estimator was formally failed.

## Went right
1. Smoke tests before any real statistic caught a real confound: the detection floor turns selection into apparent instruction. No real data were touched.
2. The split-test null (size-binned clone swap) passed all three synthetic scenarios at first try.
3. Novelty was checked down to the claim level, and the split test was rewritten to claim only what is unpublished (Bence's push).

## Went wrong
1. **Pass rule set before the structure count it depended on.** Amendment 4 fixed floors 1/3/5 without the train minimum clone size, which was measured in the same run (3). Lesson: measure the structural regime (floors, sizes, arm counts) before fixing smoke pass rules over it.
2. **Exposure slip in the novelty scan (2026-11-18):** a sentence filter still printed one pooled result sentence from the source paper of a sealed set. Lesson: scans of a sealed set's source paper print section headings and design sentences matched by keyword only, never sentences containing statistics words (r =, P =, correlation of).
3. **JSON writer crash twice** (numpy bool in print and dump). Lesson: smoke the writer itself locally with a 1-rep run before dispatch.
4. **Accidental commit of untouchable files (git commit -a), 2026-11-18.** Lesson: stage by name only.
5. Amendments 1-3 were made at the pre-registration stage, before any run. Four amendments look like drift but were mostly design. Lesson: design changes before the first run go into a single revised pre-registration, not stacked amendments.

## Lessons landed
- L1 (measure regime before pass rules): **practice line** added to program.md checklist.
- L2 (sealed-source scans: headings and design sentences only): **memory** (feedback_holdout_discipline.md) plus a practice line.
- L3 (1-rep local writer smoke): **practice line**.
- L4 (stage by name): **memory** (feedback_cellware_save_hygiene.md).
- L5 (single revised pre-registration before the first run): **not adopted** as a rule (H18 already caps it); noted.
