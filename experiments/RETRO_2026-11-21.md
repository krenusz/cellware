## The block in one paragraph
The stage-aware memory model moved from the PEtracer trees to a second, dated embryo tree (DNA Typewriter mouse, one embryo). The tree passed its structure gate on the second try (split-age-stratified picker) and was sealed by founder clade before any cell type was read (train 38, A 19, B 18, C 18). Three nested fits on the train clades were all **NOT SUPPORTED**, each powered at its own fitted label noise: edge depth with the coarse label (10/27 clades), a date clock for commitment plus memory per division (12/27), and edge depth with the finer label (9/27). Commitment carries the fit; memory per division edge (~0.86-0.90) adds little. Committing by the date clock fit 5.4% better than by edge depth (19/27 clades, exploratory), but a sealed-A confirmation was pretested at power 0.43 and not run. The embryo tree became pluripotent system 3 in the parameter table (commitment identified, memory not). The law-test count gate is now met for blood and pluripotent, but the test is not feasible: no parameter is shared by two pluripotent systems, and even the best case gives p >= 0.086. **No sealed partition was read; every A/B/C is intact.**

## Went right
1. **Sealing before any label read**, by founder clade, balanced by first-cleavage half (partitions.dtt_founder), after a structure gate that stopped once (G2) and passed on a pre-written amendment.
2. **Every negative is powered at its real noise** (P6 at 0.57, P3 at 0.69). "Memory adds little" is now a result, not an absence of power.
3. **Pretests killed five options without spending data or compute** (time-since-split collinear on an ultrametric tree; no second embryo; no other systems with split depths; sealed-A clock test at 0.43; law test at best-case p 0.086).
4. **A stayed sealed in front of a tempting lead.** The clock lead (5.4%, 19/27) was pretested on spent train numbers first; the pretest showed founder heterogeneity (sd 0.0097 vs mean 0.0037) would waste the partition.
5. **Derived covariates were checked for robustness before use:** split dates agree at Spearman 0.995 between the age-ladder and unconstrained dating trees (clades matched by leaf-set hash, since node order differs).

## Went wrong (each lesson lands)
1. **Options were proposed before they were pretested (main finding).** The time-since-split re-run was offered although every leaf of the tree sits at 13.5 days (date and time since split are collinear, -1.00). Bence: "can you just do a lot of pretest and see what could even work? before suggesting me a lot of shit that cannot??"
   -> practice (program.md, "Before proposing next steps"): pretest every candidate, list only passes, name what failed and why.
   -> memory (feedback_cellware_preflight.md, project_cellware_c17_options.md).
2. **The first power check used the wrong noise.** P1/P2 simulated at eps 0.12; the real fits came out at 0.57 (T) and 0.69 (T4), so two verdicts needed after-the-fact power checks (P6, P3).
   -> practice (program.md): power at the noise the real fit will meet; a result entry compares fitted vs pretested noise and is provisional above it.
3. **A threshold was fixed without a baseline again.** The analytic check's per-set maximum (pre-registered) could not pass by chance alone; amendment 1 (bias averaged over sets) was post hoc and logged as such. Same family as the 19b lesson ("every threshold gets a baseline").
   -> practice already exists; this is a repeat. Landing: the C17-S1PL-T3 job ran its analytic gate inside the job before any real agreement (done since T3).
4. **The law-test gate counted systems, not shared parameters or attainable p.** The count passed (blood 3, pluripotent 3) while the test was impossible.
   -> practice (program.md): compute the smallest attainable p with systems as units and check a shared parameter before calling a cross-system test open.
   -> still pending from RETRO_2026-11-20 (needs Bence's OK): a `scale` column in c17s1_params.py so the gate counts per scale.

A design that measures division count directly; a candidate 4th blood system and a direct division-vs-fate readout. Data availability not checked (unchecked lead).
  - eLife 2024 (doi 10.7554/elife.93764): single presomitic cells keep a cell-autonomous timer that uses elapsed time to set the segmentation clock's arrest. Elapsed time, not extrinsic signals, times differentiation; in kind with our exploratory clock lead.
  - Sci Adv 2025 (doi 10.1126/sciadv.adv7790): gastruloid size shifts morphogenetic timing while fate composition stays stable.
  - DeepTrack preprint 2026 (doi 10.64898/2026.08.29.748052): in vivo barcoding + multi-omics through gastrulation; data accession not given.
- What we are missing: a system where **division count is measured, not inferred from tree edges** (eLife 2021 design). Our k in edges is a proxy; the stage-aware question would be sharper with counted divisions.
