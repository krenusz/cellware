## C17 in one paragraph
C17 set out to test the project's general clone model (core_model.py) across systems and to join public data sets. Two new systems were sealed by clone before any statistic (rf2020_clone, cortical_clone; balanced, maps committed). Two embedded tests were designed, amended six times on synthetic data and train counts, and both left the sealed path by fixed rules: T-cortical (instruction vs selection under knockdown) is unbiased but underpowered at the real arm sizes (0.14-0.67), and T-split' (lineage-bias agreement of split clones beyond size) stopped at its label gate (purity 0.52). The joint fit was re-scoped (S1R): with the system as unit, three fitted systems cannot carry a law, so the model is now built system by system. **No sealed partition was read in C17; A/B/C of both new sets are intact.**

## Went right
1. **Sealing before any statistic, balanced, with committed maps** (H1, H24). Both sets were sealed in one run (63517f7) from structure only.
2. **Every stop came from a rule written before its result.** Three stops (floor-5 detection rule, power at real arm sizes, label purity gate), no re-tuning after seeing a number, no partition spent.
3. **Synthetic smoke tests caught real problems before real data:** a detection floor turns selection into apparent instruction (amendment 4), and today a flagging bug in the data sweep (hESC/mESC/hiPSC missed) was caught by its selftest before dispatch.
4. **Bence's pushes sharpened the design:** claim only the novel part (amendment 2), keep the published part as a positive control and scale (amendment 3).
5. **The re-scope counted the right unit.** The system is the unit of a cross-system law; the parameter table (c17s1_params.py, every value checked against its log line) shows 2 blood and 1 pluripotent system, so no unpowered joint fit was run.

## Went wrong (each lesson lands)
1. **The split test's novelty verdict was wrong (main finding).** lit/novelty/C17-S1.md said "not found" for "a clone's lineage bias agrees between hosts". Classic papers established it in kind:
   - Muller-Sieburg 2002 (Blood): daughter HSCs within a clone showed equivalent myeloid or lymphoid contributions across serial repopulation.
   - Dykstra 2007 (Cell Stem Cell): distinct repopulation patterns propagate on serial transplantation.
   - Yu 2016 (Cell): intra-clonal behaviour is stereotypic and conserved under transplantation.

   Our 2026-11-18 search covered recent work and the two source papers only. This is the same failure family as C16 (Colgan), with a different cause: there the source paper was unread, here the classics were never searched. No sealed look was spent (the test had already stopped), but amendments 2-3 were built on the wrong verdict. Verdicts corrected in both novelty files.
   -> practice (added today): every "not found" verdict includes a no-date concept search with the top 10 most-cited abstracts read.
   -> proposed **H25 amendment** (needs Bence's OK): make that search a required `Searched:` element.
   -> **adopted 2026-11-19, strengthened** (Bence: "can we add something to the novelty check to catch these misses? if #3 catches than good"). Backtest: a no-date search in our own wording found none of the three classics; in the field's wording ("hematopoietic stem cell clonal heterogeneity") it found all three in the top 25 (ranks 2, 10, 13); the source paper's references ranked by citations found one (rank 18). So the rule now requires the field's wording plus the reference list: a `Classic search:` line per open finding (experiments/novelty_search.py), enforced by the commit hook.
   -> memory.
2. **Four of six amendments came from facts measurable at S0 in minutes:**
   - readout coverage (lineage labels exist for 2 of 5 transplant sample sets);
   - the detection floor (3 cells);
   - real arm sizes;
   - the purity ceiling of 21 author clusters against 7 labels.

   The morning retro adopted "measure the regime first", and the label gate repeated the error the same day.
   -> practice: the S0 inventory lists the file that carries each unit's outcome and its coverage.
   -> practice: every threshold gets a baseline or ceiling estimate before it is fixed.
3. **Primary-test power came from an analytic formula.** The pre-registered cortical power (0.80 at d 0.2, sd 1, no floor) became 0.67 / 0.14 when the actual estimator was simulated at the real floor and arm sizes.
   -> practice: primary-test power at pre-registration comes from simulating the estimator at the measured regime (extends H17 to pre-registration).
4. **The headline claim's unit was not counted at S0.** C17's question (one model across systems) has the system as unit. C5-S2 had already failed the simplest memory law across classes, and the S1 joint fit was pre-registered without H19 power.
   -> practice: name and count the headline claim's unit at S0.
   -> proposed **H19 amendment** (needs Bence's OK): the chapter gate applies to the headline claim; for a cross-system claim the units are systems.
5. **A sweep was silently skipped:** run 44509258927 ran nothing because its output file already existed.
   -> fixed in tooling: run_sweep.sh now refuses a dispatch whose lines all have outputs (checked: the old c17s1_smoke5 sweep now lists no pending line).
6. Writer crash and `git commit -a`: already landed this morning (practice line, memory). Not repeated since.
7. **The neutral-wording filter was a short blocklist, and it leaked.** About 30 stems let disease-domain titles into saved outputs. Today's outputs were caught before commit. The older committed citation maps (34 tracked files, 2026-11-04 to 2026-11-19) still hold 7,822 disease-domain rows (19 with a cell-line name), and 8 other tracked notes carry a single term each (an abbreviation or a drug name). All of it is public, in the tree and in history.
   -> fixed in the tool (data sweep section).
   -> practice: before committing an output that stores external titles, probe the saved titles with the full filter.
   -> **needs Bence's decision:** scrub the older maps and notes in the tree (forward only), and whether to purge them from history (force push).
   -> **deferred** (Bence: "scrub if it benefits us if only storage wait till we have stuff"): the only gain now would be tidiness; revisit when a cleanup is worth doing.

## Decisions
- **T-split' is not restarted.** Its biological claim is published in kind. What stayed ours (agreement beyond size at single-cell lineage resolution, size-matched null) is a method refinement.
- **T-cortical stays exploratory** (descriptive decomposition on train only, if run).
- **C17 continues as S1R:** grow systems through the time-split configuration (CellTag LSK next). The law test is pre-registered only at >= 3 systems per class with identified parameters, with power counted in systems.
