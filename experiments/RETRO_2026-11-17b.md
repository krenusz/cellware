## C15 in one line
Candidate #12 (32 hosts, 78 units, lineage trees + scRNA) is usable data, but the C14 readout transferred to it cannot be powered. On train (8 hosts with a readout) the effect is about zero (-0.019), and the between-host sd is about 0.09, 2.5x C14's embryo sd. 5 hosts per sealed partition is too few. The S1b run itself was INVALID by its smoke rule. No claim. The #12 v2 partition (train 17 / A 5 / B 5 / C 5 hosts) stays sealed and unspent.

## How C15 served the long-term goal
- C15 was meant to bring the mechanistic model back on a set with fresh sealed units.
- It established that this set cannot carry a powered test of state beyond type, and that more cells per host would not fix that: the between-host variance had no 1/n term. The bottleneck is independent hosts.
- It did not fit a mechanistic model. The gap noted on 2026-11-16 (no model fit since chapter 6) is still open.

## Went right
1. **Partition before any statistic, and all three gates in order.** S0 measured structure, S0a1 rebalanced on structure only, and S1 measured noise on train only. A, B and C were never read.
2. **Structure-only reads stayed structure-only.** Raw arm and host names were recoded, and cell counts came from the named source table (RETRO_2026-11-17 lesson 1 applied).
3. **The synthetic path test caught a too-tight smoke threshold** before any real-data run (amendment 1).
4. **The result was reported as it came:** INVALID plus the power reading, with the design error owned.
5. **H24 was adopted the same day the unbalanced split showed up.**

## Went wrong
1. **The planted smoke test put y on PC0, which is depth-linked in real data and absorbed by the base model.** It passed on synthetic data, where PC0 was not depth-linked, and was uninformative on real data. The synthetic data did not mimic real data's dominant PC.
2. **The shuffled smoke test was +0.025 (3 SE) and is unexplained.**
3. **The name mask missed two gene names and the tool name.** They reached a public Actions log (run 44073504820) and the JSON. The JSON was scrubbed and the log is still public.
4. **CI lint failed for 7 pushes, and Bence got 7 emails.** Lint was not part of the pre-push routine. Separately, one push went out with a failing guard test: the check read `tail`'s exit code.
5. **The C15 power case was built on an effect transferred from embryos.** The train fit showed about zero, so S0's "optimistic" column was optimistic in effect as well as in sd.

## Lessons, each landed
| # | Lesson | Landing |
|---|---|---|
| 1 | Planted smoke signals go on a direction orthogonal to the base features (residualise against the base, or use a synthetic column), never on a raw top PC | -> practice line (program.md checklist, synthetic smoke tests) |

| 3 | Pre-push = ruff check + format check + guard tests, gated on each exit code | -> memory (done 2026-11-17) |
| 4 | A transferred effect is a hypothesis: H17 power at chapter opening states the transfer, and the train fit is the first check | -> not adopted as new: already H17; this chapter applied it |

| 6 | Delete the public log of run 44073504820 | -> asks Bence (GitHub change) |
