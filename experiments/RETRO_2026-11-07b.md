**Common root:** I acted on assumptions about the data (its unit, what it measures, how much power
it gives, whether it is accessible, whether a count is an outcome) instead of checking the cheap
metadata first. The hold-out rules (H1-H14) guard the sealed data; nothing guarded the step before:
deciding what to test, on what, and whether it can work.

## 3. Fix: a pre-flight checklist (H15), enforced

Every pre-registration from now carries a **Pre-flight** block, and the oracle refuses a look if
the experiment's section lacks it:

1. **Unit** verified from the source (sample sheet, methods, paper), quoted.
2. **Readout** verified by a structure check (columns, tags, counts), and what it measures stated.
3. **Used data first:** can open, train or spent data answer it? If yes, do that first (Bence, G13).
4. **Power** from counts and train variance (H14); stop if < 0.8 for a look.
5. **Exposure:** is any count or summary already seen an outcome for this question? Disclose.
6. **Literature access:** OA checked before calling a paper unread or paywalled.
